# 「诗芽」儿童诗词学习 TV 应用 — 设计规格

- **日期:** 2026-09-17
- **状态:** 已获用户批准
- **目标平台:** Android TV，Android 10（API 29）及以上

## 1. 项目概述

「诗芽」是一款面向 4-5 岁及以上儿童的诗词学习应用，运行在 Android TV 上。孩子在电视前跟着朗读学诗、背诗，家长通过遥控器操作。核心体验为：带逐字拼音的诗句 + 高质量有声朗读 + KTV 式逐字进度高亮 + 儿童化讲解。

## 2. 目标与成功标准

- 四五岁儿童可在家长辅助下，用遥控器完成「选诗 → 听读 → 跟读 → 看讲解」完整流程
- 在 1920×1080 电视上隔 2-3 米可清晰辨认汉字与拼音
- 完全离线可用（儿童电视环境通常无网络）
- 安装包可接受（约 100-150 MB）

## 3. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 语言 | Kotlin | Android 官方语言 |
| UI | Jetpack Compose for TV（androidx.tv:tv-material） | 官方 TV 套件，遥控器焦点系统完善，UI 完全可定制，画卷风格只能靠自定义 UI 实现 |
| 音频 | Media3 ExoPlayer | 官方媒体库，支持变速播放 |
| 数据 | 内置 JSON assets（kotlinx-serialization 解析） | 数据量小，无数据库必要 |
| 存储 | DataStore（Preferences） | 收藏、学习记录等轻量状态 |
| 网络 | 无 | 全部离线 |

- minSdk 24，targetSdk 34，单模块工程
- 包名 `com.shiya.poems`，应用显示名「诗芽」

## 4. 架构

```
UI 层(Compose TV) ←→ ViewModel ←→ Repository ←→ 内置资源
                                        ├─ poems/*.json    诗词数据(标题/作者/诗句/拼音/讲解)
                                        ├─ timing/*.json   逐字朗读时间轴(KTV 驱动)
                                        └─ audio/*.mp3     朗读音频
```

- **UI 层:** Compose TV 屏幕 + 焦点管理，无业务逻辑
- **ViewModel:** 朗读状态机（播放/暂停/语速/跟读/句跳）、收藏状态
- **Repository:** 诗词索引加载、单首诗词读取、音频路径解析
- **DataStore:** 收藏列表、最近朗读位置、语速偏好
- 模块边界：UI 不直接接触 JSON 与文件路径；朗读引擎只依赖「时间轴 + 音频路径」两个输入

## 5. 页面与导航（5 屏）

| # | 屏幕 | 内容 | 焦点交互 |
|---|---|---|---|
| 1 | 首页 | 画卷背景 + 三个入口（按难度学/按诗人学/我的收藏）+ 搜索入口 | 方向键移焦点，朱红描边 + 放大 + 阴影 |
| 2 | 难度列表 | 启蒙篇/进阶篇/小学必背三组，组内诗词卡片网格 | 左右切换组，上下翻卡片 |
| 3 | 诗人列表 | 左列诗人名，右侧该诗人诗词网格 | 左右跨列，焦点连续 |
| 4 | 朗读页 | 月夜山水长卷 + KTV 逐字高亮 + 进度条 + 控制条 + 线装书讲解 | 焦点在控制条（播放/语速/跟读/上一句/下一句），返回键退出 |
| 5 | 搜索页 | 拼音首字母选字（如 l → 李），结果列表 | TV 字母键盘 |

- 导航：Navigation Compose；返回键逐级返回
- 朗读页为全屏沉浸页，无系统状态栏干扰

## 6. 视觉规范「画卷雅韵」

### 设计语言

整屏像一幅摊开在檀木书桌上的古画手卷：锦缎包首、镶玉轴头、洒金宣纸；朗读页画心为月夜山水（满月、远山层叠、江面倒影、小舟、飞鸟、垂柳），诗词浮于画上；讲解区为翻开的线装书。

### 色彩

| 用途 | 色值 |
|---|---|
| 宣纸底 | `#F3EAD2` → `#E3D4AC` 渐变 |
| 夜天 | `#1A2338` → `#4A5568` 渐变 |
| 朱砂（焦点/高亮/印章） | `#B03A2E` |
| 月光米白（画上诗句） | `#F5ECD8` |
| 描金 | `#D9BC7A` |
| 檀木桌面 | `#50362A` → `#2A1B10` 渐变 |
| 锦缎藏蓝 | `#2C3D5E` |

### 组件规范

- **焦点态:** 朱红描边 + 1.05 倍缩放 + 阴影，全局统一
- **朗读页文字:** 汉字约 90 px，拼音约 45 px（1920×1080 基准），楷体
- **KTV 高亮:** 已读字朱砂红发光 → 当前字月光光环（米白描边圆 + 光晕）→ 未读字米白；当前行有光雾带
- **进度条:** 描金杆 + 朱砂笔尖滑块
- **控制钮:** 木质圆钮金边；主按钮（播放）朱砂底
- **焦点缩放:** 所有可聚焦元素至少 48 dp 高，间距满足 TV 安全区

## 7. 数据模型

### Poem JSON 结构（一首一个文件或按组分片）

```json
{
  "id": "tang-libai-jingyesi",
  "title": "静夜思",
  "author": "李白",
  "dynasty": "唐",
  "category": "唐诗",
  "difficulty": "qimeng",
  "lines": [
    {
      "chars": ["床", "前", "明", "月", "光"],
      "pinyin": ["chuáng", "qián", "míng", "yuè", "guāng"],
      "punct": ","
    }
  ],
  "translation": "明亮的月光洒在床前……",
  "background": "李白年轻时离开家乡……",
  "keywords": [
    { "word": "疑", "explain": "好像" }
  ],
  "audio": "audio/tang-libai-jingyesi.mp3",
  "timing": "timing/tang-libai-jingyesi.json"
}
```

### Timing JSON 结构（逐字时间轴）

```json
{
  "audioDurationMs": 26000,
  "chars": [
    { "line": 0, "index": 0, "startMs": 800, "endMs": 1250 }
  ]
}
```

### 难度定义

- **启蒙篇:** 4-6 岁，五言绝句等短小篇目，约 120 首
- **进阶篇:** 6-8 岁，七言/律诗/短词，约 150 首
- **小学必背:** 覆盖小学课标 75 + 80 篇必背目，与上两级有重叠，约 130 首

## 8. 内容管线（content-pipeline）

开发期一次性生成，产物打包进 assets：

1. **诗词数据:** 人工整理 400 首精选（唐诗约 200、宋词约 80、近现代约 60、诗经/汉乐府等约 60），含儿童化译文、背景故事、重点字词
2. **拼音:** pypinyin 生成逐字拼音，多音字人工校验
3. **音频:** edge-tts 神经网络音色（晓晓/云希，慢速）批量生成 mp3
4. **时间轴:** 从 edge-tts WordBoundary 事件提取逐字时间戳，按句切分存储
5. **校验:** 每首音频时长与时间轴对齐、拼音字数与诗句字数一致

## 9. 朗读引擎与 KTV 进度

- Media3 ExoPlayer 播放 mp3；UI 每帧按播放位置查询 timing 数据，驱动逐字动画
- **语速:** 0.6x / 0.8x / 1.0x 三档，PlaybackParameters 变速（变速后时间轴按实际位置驱动，无需换算）
- **跟读模式:** 每句读完后自动暂停，孩子跟读，按 OK 继续
- **句跳:** 上一句/下一句 seek 到该句首字 startMs
- **恢复:** 退出朗读页记住位置；重进可续播
- 音频不可用时：不崩溃，诗句与讲解仍可用，页面提示「本首音频暂不可用」

## 10. 错误处理

| 场景 | 处理 |
|---|---|
| 音频文件缺失/解码失败 | 页面提示，保留拼音与讲解，不崩溃 |
| JSON 解析失败 | 跳过该首并记录日志，不影响其余诗词 |
| 焦点意外丢失 | 恢复默认焦点（当前屏幕第一个可聚焦元素） |
| 切后台/来电 | 暂停播放并记住位置 |
| 存储读写失败 | 忽略本次收藏操作并提示 |

## 13. 范围边界（YAGNI）
